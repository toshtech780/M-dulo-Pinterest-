# Módulo Pinterest — Tosh Tech
> Módulo blindado para busca e extração de mídia do Pinterest, sem necessidade de cookies, com sistema de cache inteligente e simulação de comportamento humano para evitar bloqueios.

---

## ℹ️ Sobre
Desenvolvido por **Tosh** para a **Tosh Tech**, esse módulo permite buscar pins, extrair links de imagens em alta resolução e consultar detalhes de publicações de forma estável e segura.

✅ **Diferenciais:**
- Sem uso de cookies ou autenticação obrigatória
- Cache automático para reduzir requisições e evitar bloqueios
- Cabeçalhos otimizados simulando navegador real
- Sistema de tentativas automáticas com intervalo inteligente
- Suporte a busca por termo (nome)
- Retorna imagens em resolução original
- Código limpo, estruturado e fácil de integrar
